== Description ==
Manage your Dropbox files directly from WordPress with ease. <a href="https://codeconfig.dev/integrate-dropbox/">File Manager for Dropbox</a> lets you <a href="https://codeconfig.dev/docs/how-to-connect-my-dropbox-app-with-wordpress/">connect your Dropbox to your site</a> so you can upload, embed, and share files without touching your server space. Use it to build galleries, play videos, manage WooCommerce downloadable products, or add course materials with LMS plugins. It’s designed to save your time, reduce hosting costs, and keep everything in one place, right from your WordPress dashboard.

== Frequently Asked Questions ==

= Do I need a Dropbox account to use this plugin? =
Yes, you need a Dropbox account. The plugin connects your WordPress site with your Dropbox storage.

= Is it safe to connect my Dropbox account? =
Yes. You connect using your own Dropbox App with an App Key and Secret Key. All communication is encrypted and goes directly between your server and Dropbox. We do not store or access your files.

= Does this plugin store files on my WordPress hosting server? =
No. All files stay in your Dropbox. The plugin only displays, embeds, or links them in WordPress. This saves hosting space and bandwidth.

= Can I use Dropbox files in WooCommerce? =
Yes. With the Pro version, you can manage and sell downloadable WooCommerce products directly from Dropbox.

= Does it work with Elementor and Gutenberg? =
Yes. The plugin comes with ready-to-use widgets for Elementor and multiple Gutenberg blocks so you can easily embed galleries, file browsers, sliders, and media players.

= Can users upload files to my Dropbox through my site? =
Yes. You can allow logged-in users or form submissions (CF7, Elementor, etc.) to upload files directly to your Dropbox. You can even assign each user a personal folder.

= Can I embed videos and documents from Dropbox? =
Yes. You can embed images, videos, PDFs, Word, Excel, and other supported file formats directly into your posts and pages.

= Will the plugin slow down my website? =
No. Files are served directly from Dropbox. The plugin is optimized to minimize API calls, and caching is used to keep your site fast.

= What happens if I uninstall the plugin? =
Your Dropbox files remain safe in your account. The plugin only disconnects the link between your site and Dropbox.

= Is there a limit on the file size I can upload? =
Dropbox allows up to 350MB per file if you upload via their desktop app or API. The plugin follows Dropbox’s limits, but your WordPress server settings (PHP upload size, execution time) may also affect uploads.

= Can I restrict file access for specific users? =
Yes. You can create user-specific folders so only assigned users can view or upload files.

== Installation ==

1. Install the plugin through the WordPress admin or manually upload the integrate-dropbox folder to the /wp-content/plugins/ directory.
2. Activate the plugin through the ‘Plugins’ menu in WordPress.
3. Go to [the Developers app console](https://www.dropbox.com/developers/apps)
4. Press the blue button Create app.
5. Choose ‘Dropbox API’ for Step 1.
6. Choose ‘Full Dropbox’ for Step 2.
7. Set a unique app-name (e.g., [site-prefix]-codeconfig) for Step 3.
8. Copy and paste your APP key and App secret into the login screen, then submit credentials.
9. Add the auto-regenerated redirect URL from the login screen to App > Settings > OAuth 2 > Redirect URLs, then click on the add button.
10. Add the necessary permissions from the Permissions tab.
11. Finally, click on the sign-in button to authorize your account.
